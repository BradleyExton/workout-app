## Local Setup

Quick start on a fresh machine:

```bash
yarn install
yarn env:sync    # 1Password fetches secrets into .env.local (Touch ID prompt)
yarn dev
```

### Environment variables

This project uses the `op inject` pattern for secrets — source of truth lives in 1Password, not in any local file.

- `.env.tmpl` (committed) — declares variables and references 1Password fields via `op://Private/workout-app Supabase dev/<field>`.
- `.env.local` (gitignored, mode 0600) — generated by `yarn env:sync`. Contains the resolved plaintext values.
- `.env.local.example` (committed) — human-readable reference for what variables exist.

Prerequisites for `yarn env:sync`:

1. 1Password desktop app signed in to the **Private** vault (item: `workout-app Supabase dev`).
2. `op` CLI installed: `brew install 1password-cli`.
3. "Integrate with 1Password CLI" enabled in 1Password → Settings → Developer.

### Rotating a secret

Edit the value in 1Password → re-run `yarn env:sync` → restart `yarn dev`. No code changes.
